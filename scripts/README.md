# Enterprise Operations Scripts
This directory contains operations and automation scripts categorized by operational lifecycle:

- `database/`: Database seeding, tenant provisioning, and migration runners.
- `maintenance/`: Periodic ledger reconciliation, session purging, and temporary token cleanup.
- `development/`: Local mock generators, mock seed reloaders, and bundle analysis.
- `deployment/`: Production pre-flight checks, environment verification, and container entrypoints.
